# City View Cuts 💈

### Luxury Mobile Barbering Website

**Developed by R&L Assembled Technologies**

City View Cuts is a modern, responsive website created for a luxury mobile barbering service based in Jersey City, New Jersey.

The website provides an elegant online presence where customers can learn about the barber, explore services, view haircut portfolios, and contact the business to book appointments.

## Live Website

🌐 **[Visit City View Cuts](https://city-view-cuts-7g1.pages.dev/)**

## Features

* Luxury navy blue and champagne gold design
* Fully responsive desktop and mobile layouts
* Mobile-friendly navigation menu
* Professional barber biography
* Service descriptions and pricing information
* Interactive haircut photo gallery
* Full-screen image viewing
* Direct phone and text booking links
* Email contact integration
* Custom backgrounds and visual branding

## Technologies Used

* React
* JavaScript
* HTML5
* CSS3
* Vite
* Git and GitHub
* Cloudflare Pages

## Project Purpose

This website was developed to help City View Cuts establish a professional digital presence and make it easier for potential customers to explore services and request appointments.

The project demonstrates responsive web design, React development, interactive user interfaces, and production website deployment.
